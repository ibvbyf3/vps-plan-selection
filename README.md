## 常见问题

### 六六云支持退款吗？

不支持。开通之后不能退，也没有免费试用。所以第一次下单建议选月付最低档，把线路在自己所在的城市跑一遍，觉得可以再续。

### 六六云的机器能用来建站吗？

能。香港和美国机房都适合放站点，关键是选对机房：访客在国内选香港，访客在欧美选美国。要注意的是它的入门套餐面向的是访问量不大的站，流量和并发上来之后，配置会先撑不住，到时候要么升级套餐，要么换服务商。

### 香港和美国机房怎么选？

看两件事：访客在哪里，要不要原生IP。香港延迟低，回程走CN2 GIA和CMIN2，适合国内访客；但香港节点在测评里对ChatGPT、Claude、Gemini、Reddit是屏蔽状态。美国原生IP双ISP能解锁TikTok这类平台，代价是国内访问延迟高。两个都要，就得买两台。

### 原生IP和双ISP到底是什么？

原生IP指IP的注册地与机房所在地一致，平台识别时更像当地真实用户；双ISP指这个IP带两个运营商的属性。美国那台GTT双ISP的实测结果里，TikTok、ChatGPT、Netflix、Disney+都能正常用。平台的风控政策随时会变，测评结果只代表当时那一次。

### 晚高峰会不会掉速？

公开的测评只给了单次结果，香港那台探针测到下载127.8Mbps、上传286.5Mbps，中国移动方向有丢包。单次数据不足以下结论，稳妥的做法是月付开一台，在晚高峰用自己常用的网络跑一遍再决定要不要年付。
